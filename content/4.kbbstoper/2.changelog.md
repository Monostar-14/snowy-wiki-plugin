## 3.7.4

当前版本。

**功能**

- 定时抓取苦力怕论坛宣传帖，检测顶帖记录（Jsoup）
- `/bt binding` 绑定论坛账号，支持命令与 GUI 聊天输入两种方式
- `/bt reward` 领取顶帖奖励；`reward.auto` 可配置为自动给在线玩家发奖
- 三类奖励：普通奖励、激励奖励（久无人顶帖后的首顶）、休息日奖励（指定星期或日期）
- 防刷机制：领奖有效期（天）、同人顶帖最小间隔（分钟）、每日领取次数上限
- 箱子 GUI：绑定 / 领奖 / 排行 / 帖子链接四个功能入口，布局可配
- 顶帖列表 `/bt list` 与玩家排名 `/bt top`，支持分页
- 管理指令：`/bt check`（双向查绑定）、`/bt delete`、`/bt testreward`、`/bt reload`
- 数据库双后端：SQLite（默认）与 MySQL（多服共享）
- HTTP 代理支持，适配无法直连论坛的服务器
- PlaceholderAPI 扩展，提供 7 个占位符
- 换绑冷却与查询冷却，可用权限绕过
- 未顶帖玩家进服提示（可关闭）
- 接入 bStats 匿名统计

**与上游 BBSToper 的关系**

| 项目 | 是否通用 |
| --- | --- |
| 权限节点 | **通用** |
| 指令与别名 | **通用** |
| PlaceholderAPI 变量 | **通用** |
| 数据库 | **不通用**，迁移需玩家重新绑定 |

上游项目：[R-Josef/BBSToper](https://github.com/R-Josef/BBSToper)（Copyright © 2018-2020 R_Josef）

## 已知问题

以下问题在当前版本存在，记录在此便于后续版本跟踪：

| 问题 | 影响 | 临时规避 |
| --- | --- | --- |
| `gui.yml` 第 33 ~ 34 行使用全角引号 `‘’` | 那两行 lore 显示异常（带引号 / 显示为 `‘’`） | 手动改成标准单引号 `''` |
| `%bbstoper_lastpost%` 与 `%bbstoper_extrarewards%` 解析时会发起网页抓取 | 放在计分板/TAB 会造成大量请求与卡顿 | 只用在 GUI lore 或聊天消息里 |
| `gui.usechatgetid` 依赖聊天事件 | 与修改聊天事件的插件冲突时绑定无响应 | 设为 `false`，改用 `/bt binding` |
| `gui.displayheadskin` 获取皮肤在主线程 | 打开 GUI 可能卡顿 | 设为 `false` |
| `reward.auto` 过小会频繁请求论坛 | 可能被限流导致抓取失败 | 保持 30 秒左右，勿设为 1 ~ 5 |
| 休息日与激励奖励 `extra` 均为 `false` 且条件同时满足时 | 只发休息日奖励 | 需要两份都发就设 `extra: true` |
| `failedresolveweb` 在帖子进审核区时反复刷屏 | 控制台噪音 | 把该项留空 `''` 以禁用 |
