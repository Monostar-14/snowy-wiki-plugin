# 更新日志

---

## 1.0.0

当前版本。

**功能**

- `/sesp` 打开附魔剥离界面，把装备上的附魔摘成附魔书
- 三种支付方式：左键（金币 + 经验）、右键（点券 + 经验）、Q 键（金币 + 点券，不扣经验）
- `pricing` 多方案价格体系，按顺序自动选择第一个付得起的方案
- 支持按附魔单独定价（`pricing.enchantments.<完整命名空间ID>`）
- 字符网格自定义 GUI 布局，附魔多于 27 个时自动分页
- `blocked-lore` 按 lore 文本禁止特定物品被剥离（去色部分匹配）
- 关闭界面自动返还放入的装备
- 禁止 Shift 点击，防止物品被快速移动导致状态错乱
- Q 键支付时若点券扣除失败，自动退回已扣的金币
- 全部文案走 MiniMessage，可在 `messages` 一节自定义
- `/sesp reload` 热重载配置

**依赖**

| 依赖 | 类型 | 缺失后果 |
| --- | --- | --- |
| Vault + 经济插件 | 硬依赖 | 插件自我禁用 |
| PlayerPoints | 软依赖 | 点券支付不可用 |

**默认配置**

| 配置项 | 默认值 |
| --- | --- |
| `enchantItemSlot` | `4` |
| `price`（仅标题显示） | `300.0` |
| `pricing.defaults` | 四个方案（300金币+30经验 / 500金币 / 50点券 / 300金币） |
| `pricing.enchantments` | 消失诅咒单独配 50 点券 |
| `blocked-lore` | `["不可剥离"]` |
| `closecommand` | `trmenu open menu [Player]` |

## 已知问题

以下问题在当前版本存在，尚未修复，记录在此便于后续版本跟踪：

| 问题 | 影响 | 临时规避 |
| --- | --- | --- |
| `price` 与 `pricing` 是两套独立数据 | 标题显示的价格可能与实际扣费不符 | 改价时两处一起改 |
| 背包满时剥离出的附魔书会丢失 | 玩家损失附魔书但已扣费 | 提醒玩家留出背包空间 |
| `messages.subtitle-lore-blocked` 未写进默认配置 | 被 lore 拦截时显示代码兜底文本 | 手动在 `messages` 下补这一行 |
| 界面识别依赖标题完全一致 | 标题含动态内容时点击可能无响应 | 保持 `title` 为静态文本 |
