# GUI 与语言

## 文件分工

| 文件 | 内容 |
| --- | --- |
| `gui/gui.yml` | 主菜单、商店、已拥有、升级、玩家详情、背景与编辑器 |
| `gui/companions.yml` | 每个随从的商店图标、名称、价格、描述 |
| `lang.yml` | 聊天提示与命令帮助 |
| `config.yml` | 常规行为、数据库、兑换券，已不放菜单 GUI |

## 旧配置迁移

首次找不到独立 GUI 文件时，插件创建文件并迁入旧配置。自定义随从使用原有 GUI 段；新安装使用打包的默认图标。
一旦迁移完成，以独立文件为唯一读取来源。旧 `config.yml` 和 `companions.yml` 可能仍残留 GUI 段，但再改这些旧段不会改变菜单。
不要为了“刷新”而删除 `gui/`：这会再次触发迁移，可能读回旧设置。修改新文件后用 `/c reload`。

## 黑色玻璃背景

默认配置：

```yaml
background:
  material: BLACK_STAINED_GLASS_PANE
  name: " "
```

只填充未放物品的格子，分页先放随从，背景不会挤占分页内容。旧版缺少该材质名称时回退到旧版黑色染色玻璃板。

## 普通菜单

`GUI.open-companions`、`GUI.open-companions-shop`、`GUI.owned-companions`、`GUI.upgrade-abilities` 读取各自的标题、音效、尺寸和按钮。
槽位从 **0** 开始；建议尺寸为 9 的倍数且不超过 54。按钮槽位必须在对应菜单范围内，不要重叠。

默认主菜单大小 27，商店、已拥有与升级入口分别在 11、13、15。
共享的 `GUI.goBack.slot` 默认 45、`GUI.nextPage.slot` 默认 53，调整分页菜单尺寸时也要调整这两个位置。
`GUI.player-details` 主要配置标题/音效，详情展示复用已拥有菜单的布局，而非一套独立尺寸配置。

返回命令如 `goBackCommand: "companions"` 不带 `/`。
各菜单标题、导航按钮名、宠物图标名应区分开；现有普通菜单监听器仍有按标题/显示名称识别的逻辑。

## 编辑器

编辑器固定六行，前五行为内容，末行为操作。可在 `editor` 修改标题、按钮文字、字段标签；`editor.buttons` 调整操作按钮位置和材质，位置仅允许 45–53。
创建和保存默认都在 49，但它们位于不同界面。同一界面内的按钮不要占同一格。
删除确认界面的 20/24 槽位及图标目前固定，标题和按钮名称可配置；部分聊天输入提示写在代码中，并非全部来自语言文件。

## 帮助与配色

支持 `&7` 灰、`&8` 深灰、`&3` 暗青等传统颜色。默认使用低饱和配色。
`lang.yml` 的帮助行若以 `ADMIN:` 开头，仅有 `companions.admin.help` 的玩家可见，发送前会移除标记并只发送一次。标记必须位于行首。
