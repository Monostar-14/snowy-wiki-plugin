# 更新日志

以下按维护版本记录；验证结果来自当前源码构建与自动测试，不代表每个服务端发行版均已实测。

## 2.0.4

- 全部 10 个注册命令及别名增加参数补全，按权限、可见在线玩家和输入前缀筛选。
- 支持随从标识、升级类型、物品、布尔值与常用数量，不查询离线数据库。
- 更新检测类、导入、调用和配置项全部注释，发行 JAR 不再包含检测类。
- 保留本地版本命令。全模块构建与 21 项测试通过。

## 2.0.3

- 修复管理员帮助重复发送、ADMIN 标记外露和商店随从名称变量。
- 新增 `/c editor`：独立草稿、创建、复制、编辑、保存、二次确认删除、输入校验与冲突检测。
- GUI 拆分为 `gui/gui.yml` 和 `gui/companions.yml`，首次加载迁移旧设置。
- 空白格统一黑色玻璃板；保存前备份定义和图标。
- 删除定义后处理玩家失效的当前随从记录，保留历史拥有记录。17 项测试通过。

## 2.0.2

- 隐形盔甲架外观统一由 Bukkit API 初始化，替换各 NMS 中容易漂移的可见性/小型标记调用。
- 保留头颅、手持物品和胸甲的显示。各 NMS 模块构建及 11 项测试通过。

## 2.0.1

- 默认配置和语言中文化，低调配色，新增 8 个随从配置。
- 改用插件 Logger；修复菜单交互、分页、部分线程访问、数据保存及数据库资源管理。
- 更新 Lombok 和 MySQL 驱动，排除 VaultAPI 传递引入的旧 Bukkit API 冲突。

## 2.0.0

Gradle 多模块重构，NMS 注册范围扩展到指定 26.x 版本。后续维护均在该结构上继续，不承诺未注册版本可用。
