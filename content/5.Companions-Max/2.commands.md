# 命令与权限

`<参数>` 为必填，`[参数]` 为可选，实际输入不要带括号。随从参数使用配置中的英文标识，不是中文显示名称。

## 玩家与主命令

| 命令 | 权限 | 用途 |
| --- | --- | --- |
| `/companions`、`/c` | `companions.player.menu` | 打开主菜单 |
| `/c help` | 无额外权限 | 查看帮助；管理员条目需 `companions.admin.help` |
| `/c shop` | `companions.player.shop` | 商店；每个随从还需 `companions.buy.<标识>` |
| `/c owned` | `companions.player.owned` | 已拥有随从 |
| `/c upgrade` | `companions.player.upgrade` | 养成菜单 |
| `/c upgrade ability [true或false]` | `companions.upgrade.ability` | 升级；false 表示降级 |
| `/c upgrade rename` | `companions.upgrade.rename` | 进入改名输入 |
| `/c upgrade hidename` | `companions.upgrade.hidename` | 切换名字显示 |
| `/c upgrade changeweapon` | `companions.upgrade.changeweapon` | 进入武器修改输入 |
| `/c toggle` | `companions.player.toggle` | 召唤或收回当前随从 |
| `/c details <在线玩家>` | `companions.player.details` | 查看随从详情 |
| `/tradecompanion <在线玩家> <随从>` | `companions.player.trade` | 交易随从；别名 `/tradec` |
| `/companioncoin` | `companions.player.coin` | 查看硬币；别名 `/ccoin`、`/cc` |

直接购买升级需要已经装备随从，并满足费用、级别等实际条件。Tab 补全不代表免除这些条件。

## 管理命令

| 命令 | 权限 | 别名/说明 |
| --- | --- | --- |
| `/c editor` | `companions.admin.editor` | 游戏内编辑器，默认 OP |
| `/c reload` | `companions.admin.reload` | 重载配置；数据库连接参数变更建议重启 |
| `/c version` | `companions.admin.version` | 本地版本 |
| `/givecompanion <玩家> <随从> [true或false]` | `companions.admin.give` | `/givec`；true 为给予后装备，装备需要在线 |
| `/removecompanion <玩家> <随从>` | `companions.admin.remove` | `/removec` |
| `/givecompanionitem <在线玩家> companiontoken <数量>` | `companions.admin.item` | `/givecitem`，给予兑换券 |
| `/forceactive <在线玩家> <随从>` | `companions.admin.forceactive` | 强制装备其已拥有随从 |
| `/forcedeactive <在线玩家>` | `companions.admin.forcedeactive` | 强制收回 |
| `/forceupgrade <在线玩家> <升级类型> [true或false]` | `companions.admin.forceupgrade` | 类型同上；布尔值用于 ability，不收费 |
| `/companioncoin give <玩家> <数量>` | `companions.admin.coin` | 给予硬币 |
| `/companioncoin remove <玩家> <数量>` | `companions.admin.coin` | 移除硬币 |
| `/clearcompaniondata <玩家或all>` | `companions.admin.cleardata` | `/ccdata`；永久清除玩家数据，先备份 |

`/cc` 是硬币命令，清数据的别名是 `/ccdata`。一般玩家不应获得 `companions.admin.cleardata`。
除编辑器权限在 `plugin.yml` 中明确默认 OP 外，其他权限由命令代码检查，建议在权限插件中按需显式配置。
控制台支持主命令的 reload/version，以及适用的管理命令；界面功能需要玩家身份。

## Tab 补全

全部 10 个注册命令及其别名共享补全逻辑。支持子命令、在线玩家、当前随从目录、升级类型、兑换券、布尔值与常用数量，忽略大小写并按前缀过滤。
权限不足不显示对应建议；玩家不可见的在线目标不进入建议列表。不会为补全查询数据库或扫描离线玩家；需要处理离线玩家时手动输入名称。

例如依次输入 `/givec ` → 玩家名 → 随从标识 → `true/false`。`/c editor ` 没有额外参数，不会错误补全玩家名。
