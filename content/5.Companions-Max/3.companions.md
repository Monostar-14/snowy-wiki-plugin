# 随从配置

模型定义在 `companions.yml`，商店图标在 `gui/companions.yml`。两份文件用同一个 `companions.<标识>` 关联。
新增随从优先用[游戏内编辑器](/companions-max/editor)复制模板，以免漏掉必要字段。

## 默认示例

下方为默认配置中的第一份随从，模型与商店分开保存。材质、声音、能力名称需要与目标服务端相符。

```yaml [companions.yml]
companions:
  reaper:
    # 随从的显示名称；上方英文节点是唯一标识，请勿随意修改。
    name: "&7死神"
    nameVisible: true
    sound: ENTITY_PARROT_IMITATE_ENDER_DRAGON
    playerSkull: "eyJ0ZXh0dXJlcyI6eyJTS0lOIjp7InVybCI6Imh0dHA6Ly90ZXh0dXJlcy5taW5lY3JhZnQubmV0L3RleHR1cmUvYTM5YjVkMmU2MjRjMTQ3ZWZlNDdiMTMwZTFjZGRiOGEzNzdjZGIzZTc3NDJiZDJjZjRkZGRmNjlhNjg5MjcyIn19fQ=="
    # 使用自定义模型数据；若未设置为 "NONE" 则覆盖玩家头颅贴图。用法："材质:DATA"，如 "CLOCK:15"（时钟材质 + nbt 数据 15）。
    customModelData: NONE
    # 不需要武器时设为 NONE。
    weapon: STONE_HOE
    # 不需要能力时设为 NONE。
    # 能力前加 2@ 表示从 2 级开始。例如购买后即为 2 级力量药水。
    ability: 2@INCREASE_DAMAGE
    animation: HEADSHAKE; GHOSTLY
    chestplate: LEATHER_CHESTPLATE
    leatherColor:
      red: 32
      green: 32
      blue: 32
    # 姿势角度参考：https://haselkern.com/Minecraft-ArmorStand/
    rightArmPose:
      angle1: 360
      angle2: 270
      angle3: 286
    leftArmPose:
      angle1: 0
      angle2: 0
      angle3: 0
    headPose:
      angle1: 0
      angle2: 0
      angle3: 0
    bodyPose:
      angle1: 37
      angle2: 0
      angle3: 0
    placement:
      x: 0
      y: 1.7
      z: 0
```

```yaml [gui/companions.yml]
companions:
  reaper:
    GUI:
      shop:
        type: COMPANION_SKULL
        amount: 1
        name: "&3死神"
        price: 5000
        description:
          - " "
          - "&7掌控死亡的死神，"
          - "&7化身为可爱的随从。"
          - " "
          - "&7能力 -"
          - "&f· 伤害提升"

          - "&3左键点击 &7购买 &7死神&7 随从！"
          - " "
          - "&7价格： &f$%price%"
```

## 定义字段

| 字段 | 作用与格式 |
| --- | --- |
| `name` / `nameVisible` | 显示名称及是否显示；支持 `&` 颜色 |
| `playerSkull` | Base64 头颅贴图数据，不是玩家名或普通网页链接 |
| `weapon` | 手持材质；不用时 `NONE` |
| `chestplate` | 胸甲材质；皮革胸甲可染色 |
| `leatherColor.red/green/blue` | RGB，范围 0–255 |
| `customModelData` | 默认 `NONE`，或 `材质:整数`；实际显示还取决于资源包和版本 |
| `rightArmPose/leftArmPose/headPose/bodyPose` | 各含 `angle1/angle2/angle3`；当前配置读取整数角度 |
| `placement.x/y/z` | 随从相对偏移，允许小数 |
| `sound` | Bukkit 声音枚举名 |
| `ability` | 能力；不用时 `NONE`，多项按 `; ` 分隔，药水等级可写 `2@INCREASE_DAMAGE` |
| `animation` | 动画配置，如默认 `HEADSHAKE; GHOSTLY` |
| `bodySkull` | 额外头颅部件；沿用带此结构的既有模板，不能靠新增任意装备字段扩展槽位 |

随从本体应是隐形盔甲架，头颅、手持物品、胸甲保持显示。不要通过强制隐藏整个实体来代替盔甲架不可见，否则装备也可能消失。

## 商店字段与价格

每个随从的 `GUI.shop` 读取 `type`、`amount`、`name`、`price`、`description`。`type: COMPANION_SKULL` 使用随从头颅作图标，也支持材质名及模型数据后缀。
`price: 5000` 为 Vault 金币；`price: 5000C` 为随从硬币。价格使用非负整数，不填货币符号或千位分隔符。

`description` 中 `%companion%` 和 `%companion_l%` 使用随从配置显示名称，`%price%` 使用格式化价格。两个名称变量当前显示相同，不做中文大小写转换。
商店名称应保持唯一；部分点击逻辑使用图标显示名称识别随从，重名会影响选择。

## 能力与升级

默认自定义能力包括 LEAP、FLY、DODGE、FIREBALL、SPEED_BURST、MINING_VISION、LIGHTNING、FLING、ENDERMAN、COMMAND。
触发概率、持续时间与升级增量等在 `customability.yml`。配置文件中的注释列出了攻击/防御触发后缀的使用方式。
编辑器只是修改既有能力配置，不能通过填写新名字创建新的 Java 能力实现。

新建宠物后为玩家授予 `companions.buy.<标识>` 才会在其商店列表中出现。已购买的随从不会继续显示在商店中。
