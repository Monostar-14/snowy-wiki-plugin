# Companions-Max

基于 Astero 的 Companions 开源版维护，当前版本 **2.0.4**。随从以隐形盔甲架承载头颅、手持物品和胸甲，可配置姿势、颜色、偏移、动画与能力；提供商店、玩家养成、交易和管理员游戏内编辑器。默认包含 28 个随从配置。

源码：[Companions-Max](https://github.com/mincHR549/Companions-Max)。本手册描述当前源码行为。

## 兼容范围

| 模块家族 | 注册的版本标识 |
| --- | --- |
| 旧版 | `v1_8_R1/R2/R3`、`v1_9_R1/R2`、`v1_10_R1`、`v1_11_R1`、`v1_12_R1`、`v1_13_R1/R2`、`v1_14_R1`、`v1_15_R1`、`v1_16_R1/R2/R3` |
| 新版 | `v1_18_R1/R2`、`v1_19_R1/R3`、`v1_20_R1/R2/R3/R4`、`v1_21_R1/R2/R3/R4/R5/R6/R7` |
| 26.x | `26.1`、`26.1.2`、`26.2` 共用 MC26 实现 |

**这不是 1.8 到 26.2 的连续全版本支持。** 例如 1.17 和 1.19.3 没有对应实现。注册表共 33 项、31 个 NMS 实现；已完成构建验证，不能据此保证所有服务端发行版的实际显示效果。Paper 及其衍生端的重映射行为需要在目标版本实测。

Java 使用服务端要求的版本；源码的 core/旧版模块目标为 Java 8，新版模块按版本使用 Java 17/21，MC26 使用 JDK 25 编译工具链。

## 安装

1. 停服，把 `Companions-2.0.4.jar` 放入服务器 `plugins/`，移走同插件的旧 JAR，避免重复加载。
2. 使用金币购买时，安装 Vault 及提供 Vault Economy 服务的经济插件。Vault 本身不提供玩家余额。
3. 需要外部占位符时安装 PlaceholderAPI。聚合 JAR 已包含 CompanionsAPI、连接池和 MySQL 驱动。
4. 启动服务器，确认插件正常启用，检查 `plugins/Companions/` 生成的配置。
5. OP 使用 `/c editor` 管理随从；普通玩家按[命令与权限](/companions-max/commands)授权后使用 `/c shop`、`/c owned`。

金币依赖缺失时不要使用金币购买；硬币价格使用 `C` 后缀，详见[随从配置](/companions-max/companions)。

## 升级已有服务器

停服备份整个 `plugins/Companions/`，替换 JAR 后启动。已有配置不需要用默认文件覆盖。
首次升级到独立 GUI 结构时，会把旧 `config.yml` 的 `GUI` 和旧 `companions.yml` 的每个随从 `GUI` 迁入新文件。迁移后修改[独立 GUI 文件](/companions-max/gui)，旧段不再生效。

2.0.4 的更新检测代码已经全部注释；旧配置即使保留 `versionChecking: true`，也不会触发检测。`/c version` 只查看本地版本。
