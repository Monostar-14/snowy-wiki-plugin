# 更新日志

---

## 1.0.0

当前版本。

**功能**

- 新玩家首次加入时全服广播欢迎消息，支持 MiniMessage 与可点击按钮
- `/welcome <玩家名>` 欢迎新人，欢迎者获得奖励
- 三类独立奖励：金币（随机数额）、点券（随机数额）、自定义命令组（固定内容）
- 防滥用校验：不能欢迎自己、同一人只能欢迎一次、超过时限失效
- 欢迎成功后从 `sender-messages` 随机抽一条以欢迎者身份发到聊天
- 新人记录与欢迎关系持久化到 `data.yml`
- 接入 bStats 匿名统计（插件 ID `29514`）

**配置项**

| 配置项 | 默认值 |
| --- | --- |
| `welcome-limit-seconds` | `90` |
| `rewards.money` | 开启，100 ~ 800 |
| `rewards.playerpoints` | 开启，1 ~ 2 |
| `rewards.command` | 开启 |
